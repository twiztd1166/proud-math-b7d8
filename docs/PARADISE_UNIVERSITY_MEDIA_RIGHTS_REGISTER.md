Status: INTERNAL-USE PROJECT CONTROL — RIGHTS NOT A RELEASE BLOCKER

This file supersedes the earlier deny-by-default media-rights release gate for Paradise University v1.

## Current project decision

Paradise University is intended for Paradise employee/internal training. Under the current project scope, the curated Tony Hoty, Dave Yoho, and Grosso University recordings already held in the controlled Paradise source set may be used inside the internal training experience. Separate media-rights clearance is **not** a Paradise University release blocker.

This is a project operating decision for the internal app, not a legal opinion about copyright, licensing, or contract terms.

## Authority rule still applies

Removing the rights blocker does **not** change training authority:

- `PARADISE_APPROVED` = current Paradise-approved training/control.
- `REFERENCE` = useful trainer/source material that does not become Paradise policy merely because employees can watch it.
- `HISTORICAL` = legacy/reference material; learn the concept only where it remains consistent with current Paradise controls.
- The live municipality Lookup always controls field legality and route-specific action.
- Trainer media never authorizes doorstep pricing, financing, selling, or any other action that current Paradise policy does not authorize.

## Internal-media operating controls

1. Keep the app/internal-training use case separate from public distribution.
2. Preserve trainer/source attribution and the REFERENCE/HISTORICAL labels.
3. Do not copy trainer wording into a Paradise Approved lesson unless it is intentionally rewritten and approved as Paradise policy/training.
4. Search ranking must keep current Paradise-approved operational answers above trainer/reference material for high-risk questions.
5. Current trainer files use Google Drive preview embeds. They require network access and are **not** represented as offline-cached media.
6. Device-local `MARK COMPLETE` / `SAVE FOR LATER` may be used for media progress, but trainer-media progress is not HR certification.
7. If Paradise later records its own current modules, those should be labeled `PARADISE_APPROVED` / `PARADISE_OWNED` and can receive the full controlled-stream player features.
